# Birthday Surprise

一个适合在手机上打开的生日惊喜网页。

## 体验

- 点击红色封蜡，电子信封缓慢展开
- 奶油色贺卡从信封中升起
- 手绘生日蛋糕逐笔绘制
- 五色绣线逐字生成 “Happy Birthday”
- 生日快乐歌通过 Web Audio API 实时合成并循环播放
- 支持声音开关、重新播放和系统“减少动态效果”设置

## 本地打开

直接用浏览器打开 `index.html` 即可。所有样式、脚本和 SVG 插画均包含在文件内，不依赖外部资源。

受现代浏览器音频策略限制，需要先点击封蜡，音乐才能开始播放。

## 部署

项目可直接部署到 GitHub Pages、Netlify、Vercel 或任意静态文件服务器。
